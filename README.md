Вариант номер 16
Практика по конфигурационному управлению
Эмулятор терминала UNIX-подобной системы на языке Java. Включает в себя GUI-интефрейс на Java swing и Java awt, а также полноценные базовые команды ls(показывает содержимое директории), cd(перемещает в другую директорию или в корневую папку, если без аргумента), pwd(выводит имя текущей директории), clear(очищает терминал), exit(закрывает окно и завершает работу), help(показывает список команд).
Основные инструменты:
Java swing и awt - рисование Графического Пользовательского Интерфейса(GUI)
Многопоточность через Thread
Producer-Consumer связь через LinkedBlockingQueue и Consumer
Взаимодействие с EventDispatchThread через invokeLater и Runnable(вместо прямого помещения в память, даёт указание потом исполнить команду главному потоку)
Функциональные интерфейсы и лямбда-функции Runnable, Consumer, Supplier(имеют ровно один метод, благодаря чему Java позволяет не создавать класс, а использовать их как функцию)
Consumer<T> и Supplier<T>(используют связь accept-offer для того, чтобы возвращать и получать какие-то аргументы и делать что-то с ними)
Примерная структура рабочего цикла:
UI(реализует графический интерфейс и помещает команды в BlockingQueue)
CommandInterpreter(использует take(), чтобы взять элемент из BlockingQueue, ищет эту команду в registry, вызывает cmd.execute, если находит подходящуюю команду)
CommandContext(содержит путь cwd, список зарегестрированных команд registry, посылает в UI запрос на изменение потока EDT через invokeLater)
Activator(Является мостиком между CommandContext и CommandInterpreter(блок логики) и UI(блок интерфеййса и I/O)
