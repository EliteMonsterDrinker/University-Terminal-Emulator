Эмулятор терминала UNIX-подобной системы
Вариант 16 - практика по конфигурационному управлению
Учебный проект, представляющий собой эмулятор терминала UNIX-подобной системы с графическим интерфейсом на Java. Программа поддерживает базовый набор команд для навигации и работы с виртуальной файловой системой (VFS), а также демонстрирует применение многопоточности и функциональных интерфейсов Java.

ВОЗМОЖНОСТИ:
Графический интерфейс на Java Swing и AWT с окном эмулятора терминала.
Базовые команды для работы с файловой системой:
ls - отображение содержимого текущей директории;
cd - переход в другую директорию (или в корневую, если аргумент не указан);
pwd - вывод пути текущей директории;
clear - очистка экрана терминала;
exit - закрытие окна и завершение работы;
help - вывод списка доступных команд.
Виртуальная файловая система (VFS) на основе JSON-файлов (поддерживаются vfs_minimal.json, vfs_nested.json, vfs_source.json).
Многопоточная обработка команд через паттерн Producer-Consumer с использованием LinkedBlockingQueue.
Корректное взаимодействие с Event Dispatch Thread (EDT) через invokeLater и Runnable.

РАБОЧИЙ ЦИКЛ ПРОГРАММЫ:
Пользователь вводит команду в графическом интерфейсе.
UI помещает команду в LinkedBlockingQueue.
CommandInterpreter извлекает команду из очереди и сопоставляет её с зарегистрированными обработчиками.
Обработчик выполняет действие (например, чтение VFS, смена директории).
Результат передаётся обратно в UI через invokeLater для отображения в главном потоке.
